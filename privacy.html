Hermes: privacy policy

Last updated: 25 November 2026

Hermes is a private assistant used only by its owner, on the owner's own computer. It covers the Google OAuth apps Hermes TroyDesktop and Hermes Skills Backup. No one else can sign in to or use these apps.

What Google data it accesses

  • Gmail: read only (gmail.readonly). It cannot send, change or delete email.
  • Google Calendar: read only.
  • Google Contacts: read only.
  • Google Tasks: reads tasks and marks them complete.
  • Google Drive: only files these apps created themselves (drive.file). They cannot see any other Drive file.

How the data is used

Only to give the owner summaries, reminders and draft replies, and to back up the assistant's own settings. To do this, the relevant text is sent to the owner's AI model provider (Anthropic's Claude API) for processing, under that provider's API terms. It is not used for advertising, not sold, and not shared with anyone else.

Where it is stored

Sign-in tokens and working data stay on the owner's computer. Outputs and backups are kept in the owner's own Google Drive.

Google API Services User Data Policy

Hermes' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
